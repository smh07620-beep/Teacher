# 教師工作區 10/14 MVP 驗收清單

> 目的：在正式使用前，以實際帳號完成一次端到端驗收。此清單只涵蓋 10/14 第一階段，不包含「我的學員、臨床技能評核、能力追蹤、教學分析」。

## A. 帳號與身份切換

### A1. 純學員帳號
- 登入後可正常進入「我的學習」。
- 不應看到「教師工作區」入口。
- 不應看到「系統管理」入口。

### A2. 老師＋學員雙身份帳號
- 同一帳號可看到「📚 我的學習」與「👨‍🏫 教師工作區」。
- 切到「我的學習」後仍是原本學員首頁、課程、進度與考核流程。
- 切到「教師工作區」後只看到第一階段四個主入口：
  1. 教材與課程
  2. 媒體製作
  3. 評量與出題
  4. 紙本文件與匯出
- 切換身份不應改變伺服器權限；直接改網址參數不得取得原本沒有的管理權限。

### A3. 系統管理者
- 若同時具學員／教師能力，可分別切換「我的學習」「教師工作區」「系統管理」。
- 「系統管理」只保留人員與權限、正式文件範本、系統與儲存、Worker / Job、備份維護、安全與稽核。
- 日常教材、媒體、出題與紙本輸出不應在系統管理主導覽重複出現。

## B. 教材與課程

- 老師可看到自己權限範圍內的課程與教材。
- 組別受限教師不可切換到未授權組別。
- 新增／修改教材仍沿用既有 RBAC 與 scope。
- 媒體成品回流後，重新整理教材清單可看到新媒體教材。

## C. 媒體製作

### C1. 教材轉講稿
- 選擇既有教材。
- 送出 AI 講稿草稿工作。
- Worker 完成後可看到草稿與來源資訊。
- 老師可修改並儲存。
- 未按「教師核准講稿」前，不得進入 AI 語音正式生成。
- 已核准講稿若再次修改，應回到草稿狀態並要求重新核准。

### C2. AI 語音
- 系統狀態應顯示 AI 語音是否啟用。
- 啟用條件：Render / Worker 環境具 `OPENAI_API_KEY`，且 Cloudflare R2 已正確設定。
- 下拉選單只能選到「已核准」講稿。
- 送出後 Web 只顯示工作進度；長時間生成工作由 AI Worker 執行。
- 完成後：
  - MP3 已保存至 R2。
  - 成品自動加入原課程教材。
  - 教材清單可立即刷新看到成品。
  - 成品帶有 AI 語音揭露資訊。

### C3. 老師真人錄音
- 瀏覽器要求麥克風權限。
- 可開始／停止錄音並預覽。
- 上傳時畫面顯示 Browser → R2 進度。
- 不應把完整媒體 bytes 經 Render Web 上傳。
- Worker 後續處理完成後教材可見。

### C4. 攝影機錄影
- 瀏覽器要求攝影機＋麥克風權限。
- 可預覽錄影結果。
- 可透過既有 Browser → R2 上傳流程送入教材。

### C5. 螢幕＋麥克風錄製
- 可選擇分享畫面。
- 同時取得麥克風聲音。
- 使用者停止螢幕分享時，錄製應安全結束。
- 成品可預覽並上傳。

## D. 評量與出題

- 教師工作區主導覽可直接進入「評量與出題」。
- 題庫、考卷、考核設定沿用目前正式功能與權限。
- 「待批改／教師評核」留在評量流程內，不另外變成第五個主導覽。
- 老師只看到自己有權限管理的組別／範圍。

## E. 紙本文件與 Word 匯出

- 教師工作區可進入「紙本文件與匯出」。
- 從正式考核紀錄直接匯出 Word，不重新手打姓名、工號、分數與評核者。
- 系統依組別套用正式 Word 範本。
- 匯出資料至少可提供：
  - 文件識別碼
  - 文件／考卷版本
  - 考核日期
  - 輸出時間
  - 輸出人
  - 紙本狀態
  - 受評者簽名
  - 評核者簽名
  - 複核簽名
  - 簽核日期
  - 歸檔編號
  - 留存說明
- 列印後依科內流程完成簽核與紙本歸檔。
- 系統管理端只負責正式 Word 範本與版本治理。

## F. 手機與桌面

- 桌面版身份切換按鈕、四個教師主入口不可互相覆蓋或錯位。
- 手機版身份切換可橫向捲動，不應變成遮住內容的固定底部列。
- 教師工作區四個主入口均可點擊。
- 媒體製作表單不得超出螢幕寬度。
- 錄製按鈕在不支援的瀏覽器需顯示清楚錯誤，不可讓整頁失效。

## G. 上線前必要檢查

- GitHub `main` 的 Teacher release checks 綠燈。
- Playwright UI checks 綠燈。
- Windows Worker checks 綠燈。
- Render 部署版本 SHA 與預定驗收的 `main` SHA 相同。
- Supabase migrations 已套用到目前版本。
- R2 設定正常。
- Material Worker 有 heartbeat 且狀態可見。
- 若要使用 AI 講稿／AI 語音，AI Worker 正常執行且可讀取必要環境變數。
- 用至少一個「學員」、一個「老師＋學員」、一個「系統管理者」帳號各跑一次上述路徑。

- 臨床技能評核
- 能力追蹤
