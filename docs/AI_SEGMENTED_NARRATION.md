# AI 語音：逐張投影片分段、台灣用語與發音校正（2026-10-10）

## 學員看到的行為

- 打開教材（或翻到某一張）才播那一張的講解，**講完就停住**，不會自動翻頁，也不會接著講下一張。
- 學員自己翻到下一張，才開始播下一段；翻回前一張可以重聽。
- 播放列的按鈕在講完後會變成「🔁 重聽本頁」。喇叭關閉的偏好照舊（關閉時翻頁也不會出聲）。
- 沒有分段資料的舊語音、或教材在語音產生後被改版（`stale`）時，維持原本的整段播放。

## 什麼時候會逐張分段

AI Worker 產生語音時，把已核准講稿依「空白行」切成段落，**段落數剛好等於來源教材的頁數**才會逐張分段。
講稿產生器已被要求「第 k 段對應第 k 張」。數量不一致時（手動改過講稿、非投影片教材）維持整段播放，
語音工作的結果會附上 `segmentNote` 說明原因。內容只有「【需教師補充】」的段落會保留該張位置但不出聲。

## 資料格式（沒有新資料表）

語音教材列的 `storage_meta`（JSON）新增：

| 欄位 | 說明 |
|---|---|
| `segmented` | `true` 代表逐張分段 |
| `segments` | `[{"page": 0, "startMs": 0, "endMs": 8200}, ...]`，頁碼從 0 起，只含講話時間 |
| `durationMs` | 整段長度 |
| `sourceVersion` | 產生語音時來源教材的版本，用來判斷教材之後是否改版 |

仍是**一個** WAV 檔（段與段之間靜音 `SEGMENT_GAP_MS` = 400 毫秒），所以 R2、下載與舊播放器都不受影響。
學員端 API（`_attach_narrations`）會給 AI 語音附上 `kind: "ai"`、`segments`、`durationMs`、`stale`。
只改某一張的講稿時，沒改過的段落直接用本機合成快取，只重新合成改過的那一張。

## 台灣用語

- 講稿提示詞新增規則 8：使用臺灣醫事檢驗慣用詞彙，不使用中國大陸用語。
- 產生後再以 `tts_text.TAIWAN_TERM_FIXES` 做一次保守取代（只放不會有歧義的詞，例如質控→品管、信息→資訊）。
  「質量」「樣本」「標本」這類有歧義的詞刻意不處理，由老師自己判斷。

## 發音校正表

檔案：`teacher_app/materials/tts_pronunciation_table.json`。只影響**唸出來的字**，投影片、講稿、字幕都不變。

- `terms`：`{"match": "HbA1c", "say": "糖化血色素"}`。英文縮寫只在前後不是英數字時才會被取代（`PT` 不會改到 `OPTIMAL`）。
- `regex`：數字相關規則，例如 `5.7%` 唸成「百分之5.7」、`37°C` 唸成「攝氏37度」、`ISO 15189` 逐位唸。
- 新增或修改後，到 GitHub Actions 執行「Release Worker」，院內 AI Worker 更新後生效（本機語音快取以最終唸出的文字為鍵，所以改了校正表會自動重新合成）。

## Worker 自動更新間隔

`MATERIAL_WORKER_UPDATE_INTERVAL_MINUTES`（預設 15，最短 5）取代原本最短 1 小時的限制；舊的 `..._HOURS` 仍可用，但分鐘優先。
更新器只在 Worker 閒置時於本機執行，只抓一個核准標籤，網站仍不能遠端下令更新。

## 進度列的「預估還需約 N 秒」

AI 語音產生時，進度文字會附上「預估還需約 N 秒（或 M 分 SS 秒）」，網頁每秒自動倒數。
預估 = 剩餘字數 × 每字秒數。預設每字 0.25 秒（環境變數 `AI_VOICE_SECONDS_PER_CHAR` 可改）；
Worker 實際合成後會依本機速度自動學習，同一次開機內之後的預估會越來越準。使用快取的段落幾乎不花時間，所以實際可能比預估更快。
