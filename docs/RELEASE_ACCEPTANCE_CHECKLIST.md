# 部署後人工驗收清單（教師／學員主流程）

自動化測試涵蓋程式邏輯與瀏覽器操作，但「轉檔品質」與「正式環境設定」仍需要人看一次。
每次部署到 Render、或更新本機 Worker 之後，照下列順序走一遍，約 10 分鐘。

## A. 系統與 Worker

1. 開啟 `/health`：`status=healthy`、database 與 migrations 為 OK，並看 `configuration.warnings` 是否只有已知項目。
2. 後台「Worker / Job 狀態」：Worker 顯示 online，版本與網站版本一致（沒有「版本不符」警告）。
3. 若 Worker 是離線，先在 Worker 電腦開機並確認 Task Scheduler 任務執行中，再繼續。

## B. 教師：上傳 → 轉檔 → 預覽 → 發布

1. 「＋ 建立教學內容」上傳一份 **PPTX**（含中文、最好有自動縮小文字的版面）和一份 **PDF**。
2. 上傳進度依序前進：R2 接收 → 等待 Worker → 下載／驗證 → 轉檔／預覽 → 正式發布 → 完成。
3. 到後台教材列表，確認該教材卡片：
   - 若出現黃色「⚠ 轉檔版面可能與原檔不同」，代表轉檔主機缺字型或原檔有自動縮小文字。
   - 打開閱讀器逐頁比對原檔；若有文字重疊，在 PowerPoint 選「另存新檔 → PDF」後改傳 PDF。
4. 完成課程精靈第 4 步「確認與發布」，確認發布檢查通過後才讓學員看到。

## C. 學員：閱讀 → 考試

1. 用學員帳號開啟剛發布的教材：
   - 按「›」「‹」鈕與鍵盤 ← → 都能翻頁，頁碼同步變化。
   - 在手機寬度（約 390px）重做一次。
   - 若某頁出現「這一頁暫時無法顯示」，按「重新載入此頁」能恢復，且仍停在同一頁。
2. 標記教材完成，回首頁確認「待辦／進度」更新。
3. 進入該課程考卷：作答中途重新整理頁面，答案仍在（作答暫存）；送出後看到成績與補強建議。

## D. 考題匯入

1. 在考題頁籤使用「匯入公開連結」，貼上含 1～2 題錯誤的 CSV／JSON：
   - 先出現「檢查完成：共 N 題，可匯入 X 題」並列出有問題的題號。
   - 按取消不會寫入任何題目；按確定才匯入，匯入後考卷回到待審核。

## 發現問題時

- 轉檔結果與原檔不同：先看教材卡片上的轉檔警告；改傳 PDF 是最穩定的做法。
- 頁面圖片載入失敗：先按閱讀器的「重新載入此頁」；持續失敗請看 `/health` 與 Worker 狀態，教材圖片目前僅在 MEGA 單一預覽模式下由網站即時產生。
